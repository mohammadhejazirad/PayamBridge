# Security policy

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature for this repository. Do not include real tokens or customer data in a public issue. If private reporting is unavailable, contact the maintainers through the repository profile and request a private channel before sending details.

Security fixes are considered for the latest supported release line. This project is currently in its initial development stage; the implementation status and coverage limits are documented in [docs/IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md). We have not established a response-time guarantee or a long-term support schedule.
